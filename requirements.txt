# VENOM default install profile (minimal API / cloud-first)
#
# This default intentionally does NOT install local heavy LLM engines.
# It gives a lightweight start and lets user choose runtime profile later.
#
# Profiles:
# - API only:      pip install -r requirements.txt
# - API + web:     pip install -r requirements-profile-web.txt
# - Developer/medium overlay: pip install -r requirements-profile-vllm.txt
# - ONNX overlay: pip install -r requirements-profile-onnx.txt
# - ONNX CPU-only overlay: pip install -r requirements-profile-onnx-cpu.txt
# - ONNX extras: install ONNX overlay first, then:
#                 pip install -r requirements-extras-onnx.txt  (faster-whisper + piper-tts)
# - Minimal runtime: pip install -r requirements-docker-minimal.txt
# - CI gate:       pip install -r requirements-ci-lite.txt
# - Full legacy:   pip install -r requirements-full.txt
